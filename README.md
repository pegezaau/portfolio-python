# Portfólio de Programação — Python 🐍

Olá! Eu sou o **Pedro** ([@pegezaau](https://github.com/pegezaau)) e este é meu portfólio de projetos em **Python**.

Aqui você encontra 4 projetos práticos que demonstram domínio de lógica de programação, manipulação de dados, APIs REST, automação e boas práticas como organização em módulos, tratamento de erros e persistência de dados.

## 📂 Projetos

| # | Projeto | O que demonstra | Tecnologias |
|---|---------|-----------------|-------------|
| 01 | [Gerenciador de Tarefas CLI](01-gerenciador-tarefas-cli/) | CRUD completo, argparse, persistência em JSON | Python puro, JSON, argparse |
| 02 | [Analisador de Dados de Vendas](02-analisador-dados-vendas/) | Leitura de CSV, estatísticas, relatórios | csv, statistics, collections |
| 03 | [API de Biblioteca](03-api-biblioteca-flask/) | API REST, rotas, status HTTP, validação | Flask, JSON |
| 04 | [Automação e Web Scraping](04-automacao-relatorios/) | Coleta de dados da web e relatório automático | Requests, BeautifulSoup |

## 🛠️ Habilidades demonstradas
- Programação orientada a objetos e funções
- Manipulação de arquivos (CSV, JSON, TXT)
- Criação de APIs REST com Flask
- Automação de tarefas e web scraping
- Tratamento de exceções e validação de entrada
- Organização de código e documentação
